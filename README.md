# SAYED & LOBNA — Luxury Digital Wedding Invitation 💍✨

An interactive, international luxury digital wedding invitation web application crafted for **Sayed & Lobna**.

## 🌟 Key Features
- **Cinematic 3D Envelope**: Realistic paper texturing with an engraved royal wax seal featuring **`S & L`** side-by-side initials.
- **Glassmorphism Aesthetic**: Ice-blue, pearl-white translucent visual identity with subtle depth and dynamic blurs.
- **Editorial Typography System**:
  - English: *Cormorant Garamond*, *Playfair Display*, *Montserrat*.
  - Arabic: *Alexandria*, *Aref Ruqaa*, *Amiri*.
- **Sacred Quranic Verse**: Surah Ar-Rum (Verse 21) styled in Amiri calligraphy.
- **Live Event Countdown**: Ticking down to **Thursday, November 26, 2026, at 8:00 PM**.
- **Location Integration**: Direct access to the Google Maps venue location.

## 🚀 Deployment Instructions for GitHub Pages
1. Create a new repository on GitHub (e.g., `sayed-lobna-wedding`).
2. Upload `index.html` and `README.md`.
3. Go to **Settings** -> **Pages**.
4. Select `main` branch and `/root` folder, then click **Save**.
5. Your custom wedding website link will be generated automatically!
